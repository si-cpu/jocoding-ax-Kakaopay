# 앵커 이벤트 참조

## 이벤트 상태

| 상태 | 처리 방식 |
|---|---|
| 확정 | 공식 출처로 기준일이 확인된 뒤에만 분석한다. |
| 우려 | 비확정 선행 신호로 처리한다. 확정 이벤트로 세지 않는다. |
| 전망 | 비확정 선행 신호로 처리한다. 확정 이벤트로 세지 않는다. |
| 기대 | 약하면 분류 불가, 명확한 전환 경로가 있으면 비확정 선행 신호로 처리한다. |
| 루머 | 공식 앵커로 전환될 경로가 명확한 경우에만 비확정 선행 신호로 보고, 그렇지 않으면 제외한다. |
| 해설/논평 | 명확한 공식 앵커를 가리키지 않으면 제외한다. |

## 기업 앵커 이벤트

### 실적 발표

- 공식 출처: DART/금융감독원 공시, 회사 IR, 실적 발표 자료
- 포함: 분기/반기/연간 실적, 잠정 실적
- 제외: 실적 기대감, 애널리스트 전망, 업황 해설
- 비정형 입력 예: 최대 실적, 어닝 서프라이즈, 실적 쇼크

### 배당 결정

- 공식 출처: DART/금융감독원 공시, KRX, 회사 IR
- 포함: 현금배당, 주식배당, 배당정책 발표
- 제외: 배당 기대감, 배당 확대 전망
- 비정형 입력 예: 배당 늘린다, 고배당, 주주환원

### 공급계약/수주

- 공식 출처: DART/금융감독원 공시, KRX, 회사 공식 발표
- 포함: 단일판매·공급계약, 대형 수주
- 제외: 수주 기대감, 협상 중, MOU만 언급된 경우
- 비정형 입력 예: 대형 수주, 공급계약, 계약 체결

### 신규 시설투자

- 공식 출처: DART/금융감독원 공시, KRX, 회사 IR
- 포함: 신규 공장, 시설 투자, 생산능력 확대
- 제외: 투자 검토, 투자 기대감, 투자 전망
- 비정형 입력 예: 공장 증설, 설비 투자, 투자 확대

### 유상증자/무상증자

- 공식 출처: DART/금융감독원 공시, KRX
- 포함: 유상증자, 무상증자
- 제외: 자금조달 루머, 증자 가능성
- 비정형 입력 예: 유증, 무증, 신주 발행

유상증자와 무상증자는 의미가 다르므로 가능하면 하위 앵커를 분리한다.

### 자기주식 취득/처분

- 공식 출처: DART/금융감독원 공시, KRX
- 포함: 자사주 매입, 자사주 소각, 자기주식 처분
- 제외: 자사주 매입 기대감, 주주환원 전망
- 비정형 입력 예: 자사주 매입, 자사주 소각, 자기주식 처분

취득과 처분은 성격이 다르므로 가능하면 분리해 표시한다.

### 합병/분할

- 공식 출처: DART/금융감독원 공시, KRX
- 포함: 합병 결정, 회사 분할, 분할합병
- 제외: M&A 검토, 시장 루머
- 비정형 입력 예: 합병, 분할, 지배구조 개편

### 생산중단

- 공식 출처: DART/금융감독원 공시, KRX, 회사 공식 발표
- 포함: 공장 가동중단, 조업중단, 공식 확인된 생산 차질
- 제외: 파업 예고, 생산 차질 우려, 노사 협상 전망
- 비정형 입력 예: 파업, 조업중단, 생산 차질

중요 원칙:

- “파업 우려”는 생산중단 확정 이벤트가 아니라 생산중단 후보일 뿐이다.
- 생산중단이 공식 확인되지 않으면 비확정 선행 신호로 처리한다.
- 뉴스/검색은 파업 가능성, 찬반투표, 임단협 결렬 등 선행 신호를 포착하는 데 사용한다.
- 뉴스/검색에서 포착된 신호는 공식 생산중단이 아니라 비확정 선행 신호다.
- 파업 가능성, 임단협 결렬, 노조 찬반투표, 총파업 예고, 생산 차질 우려를 공식 생산중단으로 처리하면 안 된다.
- 확정 생산중단에는 공식 생산중단, 조업중단, 회사가 확인한 생산 차질 기준일이 필요하다.
- 기업 공시 확인은 OpenDART 공시검색 API를 1차 게이트로 사용한다.
- `report_nm`에서 `생산중단`, `영업정지`, `조업중단`, `주요사항보고서`, `거래소공시` 등 확정 앵커 후보를 확인한다.
- `rcept_no`가 있으면 `https://dart.fss.or.kr/dsaf001/main.do?rcpNo=접수번호` 형식으로 원문 링크를 만든다.
- DART에서 관련 공시가 없으면 “생산중단 공시 미확인”으로 표시한다. 단, 이는 파업이 없었다는 뜻이 아니라 확정 생산중단 앵커를 확인하지 못했다는 뜻이다.
- 파업 회피/합의/철회/타결은 DART에 없을 수 있으므로 회사 공식 발표, 노조 공식 발표, KRX 공시, 신뢰 가능한 공식 보도자료로 보완 확인한다.
- 공식 확인 전 파업 우려는 확정 생산중단 사례로 직접 비교하지 않는다.
- 대신 유사한 파업/노사 신호를 다음 두 갈래로 나눠 교육용 참고로 보여줄 수 있다.
  - 파업 발생/생산중단 전환 사례
  - 파업 회피/합의/철회/타결 사례
- 두 갈래 모두 공식 기준일이 확인된 경우에만 3·5·10영업일 주가증감을 표시한다.

사용자 문구 예:

```text
파업 우려와 공식 생산중단은 다릅니다.
현재 입력은 생산중단 앵커가 아니라 생산중단 후보에 해당하는 비확정 선행 신호입니다.
공식 생산중단 공시나 회사 공식 확인 전에는 생산중단 사례로 확정 비교하지 않습니다.
```

### 파업/노사 신호의 두 갈래 시나리오

| 갈래 | 의미 | 기준일 |
|---|---|---|
| 파업 발생/생산중단 전환 | 파업 신호가 실제 파업, 조업중단, 생산 차질 공식 확인으로 이어진 경우 | 공식 생산중단일, 조업중단일, 회사 공식 확인일 |
| 파업 회피/합의/철회/타결 | 파업 신호가 임단협 타결, 파업 철회, 무분규 합의 등으로 끝난 경우 | 공식 합의일, 철회 발표일, 타결 발표일 |

필수 경고:

```text
현재 입력은 아직 확정 이벤트가 아니므로, 생산중단으로 단정하지 않습니다.
대신 과거 유사한 파업 신호가 실제 파업/생산중단으로 이어진 경우와, 합의·철회로 파업을 피한 경우를 나눠 참고할 수 있습니다.
```

### 생산재개

- 공식 출처: DART/금융감독원 공시, KRX, 회사 공식 발표
- 포함: 생산재개, 공장 재가동, 조업 정상화
- 제외: 재개 기대감, 협상 재개
- 비정형 입력 예: 생산 재개, 공장 다시 가동, 조업 정상화

생산중단과 생산재개는 별도 앵커다.

### 거래정지/거래재개

- 공식 출처: KRX
- 포함: 거래정지, 거래재개
- 제외: 거래정지 가능성, 상장폐지 우려
- 비정형 입력 예: 거래정지, 거래재개, 매매정지

### 소송/수사

- 공식 출처: DART/금융감독원 공시, KRX, 법원/검찰/규제기관 공식 발표
- 포함: 중요 소송, 판결, 압수수색, 공식 수사
- 제외: 소송 가능성, 익명 제보, 루머
- 비정형 입력 예: 소송, 수사, 압수수색, 벌금

## 거시/정책 앵커 이벤트

### 기준금리 결정

- 공식 출처: 한국은행
- 포함: 기준금리 인상, 인하, 동결
- 제외: 금리 전망, 인하 기대, 시장 예측
- 비정형 입력 예: 금리 올림, 금리 내림, 금리 동결

인상/인하/동결은 별도 하위 앵커로 본다.

### 환율 급등락

- 공식/시장 출처: 한국은행, 공식 외환시장 데이터, 신뢰 가능한 시장 데이터
- 포함: 확인된 원/달러 환율 급등락
- 제외: 환율 전망, 환율 우려, 논평
- 비정형 입력 예: 환율 급등, 원화 약세, 달러 강세

수치 기준은 구현 단계에서 정의한다.

### 물가 지표 발표

- 공식 출처: 통계청, 한국은행
- 포함: CPI/PPI 또는 공식 물가 지표 발표
- 제외: 물가 우려, 물가 전망
- 비정형 입력 예: 물가 상승, CPI 발표, 인플레이션

### 정부 규제/정책 발표

- 공식 출처: 정부부처, 금융위원회/금융감독원, 관련 규제기관
- 포함: 규제 발표, 정책 시행, 산업 정책
- 제외: 정책 검토, 규제 가능성, 정치인 발언만 있는 경우
- 비정형 입력 예: 정부 규제, 정책 발표, 산업 규제

### 세제 개편

- 공식 출처: 기획재정부, 국세청, 정부부처
- 포함: 세제 개편안, 세율 변경, 세금 정책 발표
- 제외: 세금 우려, 세제 개편 전망
- 비정형 입력 예: 세제 개편, 세금 정책, 감세

### 업종 지원책

- 공식 출처: 정부부처, 정책브리핑, 산업통상자원부, 금융위원회 등
- 포함: 특정 업종 지원, 보조금, 정책금융, 세제 지원
- 제외: 수혜주 언급, 지원 기대감, 정치인 발언만 있는 경우
- 비정형 입력 예: 반도체 지원책, 배터리 보조금, 정책금융

## 제외 또는 보류 예시

다음 입력은 제외하거나 보류한다.

- “요즘 이 종목 관심 많다던데?”
- “수혜주라던데?”
- “실적 좋아질 것 같다던데?”
- “파업할 수도 있다던데?”
- “정부가 뭔가 지원할 것 같다던데?”
- “저평가라던데?”
- “커뮤니티에서 악재라고 하던데?”
- 계좌번호, 비밀번호, 인증번호, 주민등록번호, 전화번호, 이메일, 보유수량, 평균단가, 평가금액, 손익률 등 개인·계좌·인증 정보가 포함된 입력
- 증권 앱 잔고/수익률/주문 화면 캡처

단, 명확한 앵커 후보와 전환 경로가 있으면 비확정 선행 신호로 설명할 수 있다.

민감정보 포함 입력은 예외적으로 전환 경로가 있더라도 앵커 이벤트 분석을 진행하지 않는다. 출력 상태는 `민감정보 포함으로 분석 불가`로 표시하고, 민감정보 제거 후 회사명과 사건 문장만 다시 입력하도록 안내한다.

## 구간 내 보조 이벤트 확인

3·5·10영업일 주가증감을 보여줄 때는 해당 구간 안에 다른 이벤트가 있었는지도 함께 확인한다.

확인 구간:

- 기준일 이전 1주일
- 기준일~3영업일
- 3~5영업일
- 5~10영업일

확인 범위는 MVP 범위로 제한한다.

- 같은 회사의 확정 앵커 이벤트
- 같은 회사의 비확정 선행 신호
- 관련 업종의 주요 앵커 이벤트
- 공식 출처 또는 시장 데이터로 확인 가능한 시장 맥락 앵커
- 기준 이벤트와 직접 관련된 후속 공시 또는 정정 공시

필수 경고 문구:

```text
이 구간의 주가증감은 기준 이벤트 하나만의 결과로 볼 수 없습니다.
아래 기간에 다른 앵커 이벤트 또는 시장 맥락이 발생했는지 함께 확인해야 합니다.
```
