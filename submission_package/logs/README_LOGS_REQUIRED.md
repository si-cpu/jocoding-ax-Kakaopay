# logs 폴더 안내

해커톤 제출 규정상 이 폴더에는 플러그인을 만들면서 AI와 주고받은 전체 대화 로그를 원본 그대로 넣어야 합니다.

주의:

- 편집, 발췌, 삭제, 요약 없이 전체 로그를 제출해야 합니다.
- 제출 가능한 형식은 `md`, `txt`, `json`, `jsonl`입니다.
- API 키, 비밀번호, 토큰 등 비밀정보가 로그에 포함되지 않았는지 확인해야 합니다.
- 이 안내 파일은 실제 제출 전 원본 로그 파일과 함께 두거나, 원본 로그가 준비되면 삭제해도 됩니다.

현재 이 파일은 자리표시자입니다. 최종 제출 전 반드시 실제 원본 대화 로그를 추가하세요.
