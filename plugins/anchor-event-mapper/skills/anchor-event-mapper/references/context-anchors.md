# 시장 맥락 앵커 참조

## 목적

시장 맥락 앵커는 앵커 이벤트 주변의 시장 환경을 분류하기 위한 보조 라벨이다.

시장 맥락 앵커는 원인이 아니다.

공식 출처 또는 시장 데이터로 확인 가능한 경우에만 사용한다. 불명확하면 `맥락 미분류`로 표시한다.

합병 승인, 정책 압박, 반도체 사이클, 환율, 금리, 시장 급락/급등은 분석 대상의 주 앵커가 아닌 한 주가 변동의 원인으로 제시하지 않는다. 보조 맥락 또는 구간 내 보조 이벤트로만 표시한다.

## 시장 맥락 앵커

### 금리/통화정책

- 출처: 한국은행
- 포함: 기준금리 결정, 공식 통화정책 문구
- 제외: 금리 전망, 시장 기대, 논평
- 입력 예: 금리 올림, 금리 내림, 긴축, 완화

### 환율 급등락

- 출처: 한국은행, 서울외환시장 데이터, 신뢰 가능한 시장 데이터
- 포함: 확인된 원/달러 환율 급등락
- 제외: 환율 전망, 환율 우려, 논평
- 입력 예: 환율 급등, 원화 약세, 달러 강세

수치 기준은 구현 단계에서 정의한다.

### 물가/인플레이션

- 출처: 통계청, 한국은행
- 포함: CPI/PPI 발표, 공식 물가 지표
- 제외: 물가 우려 또는 전망만 있는 경우
- 입력 예: 물가 상승, CPI, 인플레이션

### 전쟁/지정학 리스크

- 출처: 정부부처, 외교부, 국제기구, 공식 성명
- 포함: 전쟁 발발, 군사 충돌, 제재, 외교 위기
- 제외: 루머, 커뮤니티 글, 추측성 해설
- 입력 예: 우크라이나 전쟁, 이란 미국 긴장, 지정학 리스크

### 관세/무역분쟁

- 출처: 기획재정부, 산업통상자원부, 관세청, 정부/국제기구 공식 발표
- 포함: 관세 인상, 무역 협정, 수출입 제한, 무역분쟁
- 제외: 관세 우려, 협상 가능성, 정치인 발언만 있는 경우
- 입력 예: 관세 협정, 미국 관세, 수출규제, 무역분쟁

### 정부 규제/정책

- 출처: 정부부처, 금융위원회/금융감독원, 규제기관
- 포함: 공식 규제 또는 정책 발표
- 제외: 규제 가능성, 정책 검토, 정치인 발언만 있는 경우
- 입력 예: 정부 규제, 정책 발표, 산업 정책

### 업종 사이클

- 출처: KRX 업종지수, 카카오페이증권 내부 업종 분류, 신뢰 가능한 업종 데이터
- 포함: 데이터로 확인되는 업종 단위 움직임 또는 사이클
- 제외: 단일 기사나 논평만 있는 경우
- 입력 예: 업황 개선, 업황 둔화, 반도체 사이클

MVP에서는 보조 태그로만 사용한다.

### 시장 급락/급등

- 출처: KRX 지수 데이터
- 포함: KOSPI/KOSDAQ 또는 관련 지수 급락/급등
- 제외: 막연한 투자심리 언급
- 입력 예: 코스피 급락, 시장 폭락, 증시 반등

수치 기준은 구현 단계에서 정의한다.

## 필수 경고 문구

시장 맥락 앵커를 표시할 때는 다음 문구를 포함한다.

```text
시장 맥락 앵커는 당시 시장 환경을 이해하기 위한 보조 분류입니다.
주가 증감의 원인으로 단정하지 않습니다.
```

구간 내 보조 이벤트를 표시할 때는 다음 문구를 포함한다.

```text
이 구간의 주가증감은 기준 이벤트 하나만의 결과로 볼 수 없습니다.
아래 기간에 다른 앵커 이벤트 또는 시장 맥락이 발생했는지 함께 확인해야 합니다.
```
