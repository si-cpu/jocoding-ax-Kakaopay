# 사용자 응답 테스트: Anchor Event Mapper

테스트 일시: 2026-07-08  
테스트 목적: 플러그인이 실제 사용자에게 어떤 형태로 응답해야 하는지 확인  
테스트 입력:

```text
회사명: 삼성전자
입력 문장: 삼성전자 노조 총파업으로 생산 차질 우려가 있다는데, 과거엔 주가가 어떻게 움직였어?
```

---

## 사용자에게 보여줄 응답 예시

먼저 이 문장은 바로 `생산중단` 이벤트로 확정하면 위험합니다.

현재 입력은 `파업 우려`와 `생산 차질 가능성`에 관한 문장이므로, 공식 생산중단 공시나 회사 공식 확인 전까지는 다음처럼 분류합니다.

| 항목 | 판단 |
|---|---|
| 회사 | 삼성전자 |
| 입력 사건 | 노조 총파업, 생산 차질 우려 |
| 상태 | 비확정 선행 신호 |
| 앵커 후보 | 생산중단 |
| 확정 앵커 여부 | 아님 |
| 분석 상태 | 제한적 참고 가능 |

### 왜 바로 생산중단으로 보지 않나요?

`파업 우려`, `파업 가능성`, `총파업 예고`, `임단협 결렬`은 실제 공장 가동 중단과 다릅니다.

따라서 이 입력은 `생산중단 앵커`가 아니라 `생산중단 후보에 해당하는 비확정 선행 신호`로 봐야 합니다.

공식 생산중단 공시나 회사 공식 확인 전에는 생산중단 사례로 확정 비교하지 않습니다.

## 기준일 이후 주가증감

이 수치가 파업 우려 하나 때문에 발생했다는 뜻은 아닙니다.

기준일: 2024-07-08  
기준 종가: 87,400원

## 구간 내 보조 이벤트 확인

이 구간의 주가증감은 기준 이벤트 하나만의 결과로 볼 수 없습니다.  
아래 기간에 다른 앵커 이벤트 또는 시장 맥락이 발생했는지 함께 확인해야 합니다.

| 확인 구간 | 확인해야 할 항목 | 현재 테스트 응답 |
|---|---|---|
| 기준일 이전 1주일 | 이미 반영됐을 수 있는 파업 예고, 반도체 업종 이슈, 시장 급락/급등 | 추가 확인 필요 |
| 기준일~3영업일 | 실제 생산중단 공시 여부, 회사 공식 입장, 반도체 업종 동향 | 추가 확인 필요 |
| 3~5영업일 | 파업 장기화 여부, 후속 노사 협상, 시장 맥락 변화 | 추가 확인 필요 |
| 5~10영업일 | 추가 공시, 반도체 사이클, 환율/금리/시장 급락 여부 | 추가 확인 필요 |

시장 맥락 앵커는 당시 시장 환경을 이해하기 위한 보조 분류입니다.  
주가 증감의 원인으로 단정하지 않습니다.

## 교육 포인트

이 사례에서 가장 중요한 점은 `파업 우려`와 `공식 생산중단`을 분리하는 것입니다.

초보 투자자는 “파업”이라는 단어만 보고 곧바로 악재 또는 생산중단으로 받아들이기 쉽지만, 투자 판단에서는 다음 순서로 봐야 합니다.

1. 실제 공식 이벤트인가?
2. 아니면 우려·전망·가능성인가?
3. 기준일을 공식 출처로 잡을 수 있는가?
4. 기준일 이후 3·5·10영업일 사이에 다른 이벤트가 끼었는가?

이 입력은 현재 `비확정 선행 신호`이므로, 생산중단 사례처럼 단정 비교하면 안 됩니다.

## 주의

- 과거 주가증감은 미래 예측이 아닙니다.
- 이 결과는 투자 권유나 매수·매도 추천이 아닙니다.
- 파업 우려, 반도체 업종 흐름, 환율, 금리, 시장 급락/급등 등은 서로 섞여 주가에 영향을 줄 수 있습니다.
- 공식 출처로 확인되지 않은 사건은 확정 앵커 이벤트로 처리하지 않습니다.
