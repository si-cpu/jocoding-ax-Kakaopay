## 4. 이전 방식과 지금 방식의 차이

### 이전 방식: 뉴스/검색 기반 비확정 신호

이전 실습에서는 2026-06-24 `현대차 국내 노조 파업 찬성 투표` 보도를 기준으로 봤다.

이 사건은 공식 생산중단이 아니라 `비확정 선행 신호`다.

해석 제한:

- 이 수치는 `파업 찬성 투표 이후` 주가증감이다.
- 공식 생산중단 공시 기준이 아니므로 `생산중단 효과`라고 볼 수 없다.
- 중간에 시장 급락, 자동차 업종 이슈, 환율/관세/정책 이슈가 섞였을 수 있다.

OpenDART로 확인한 결과, 현대차에는 실제 파업 관련 `생산중단` 공시와 `생산재개` 공시가 있었다.

| 항목 | 이전 방식 | OpenDART 연결 후 |
|---|---|---|
| 기준 사건 | 뉴스 기반 파업 찬성 투표 | DART 공식 생산중단/생산재개 공시 |

- 2025-09-03 생산중단 공시

## 6. 결론

OpenDART 연결 전에는 `현대차 파업`을 비확정 선행 신호로만 다룰 수 있었다.

OpenDART 연결 후에는 다음이 가능해졌다.

1. 실제 생산중단 공시 존재 여부 확인
2. 생산중단 사유가 파업인지 확인
3. 생산중단일과 결정일 확인
4. 생산재개/최종 타결일 확인
5. 파업 발생 갈래와 파업 종료/타결 갈래를 공식 기준일로 나눠 주가증감 계산

따라서 OpenDART는 이 플러그인의 신뢰성을 크게 높이는 핵심 공식 확인 게이트로 보는 것이 맞다.
