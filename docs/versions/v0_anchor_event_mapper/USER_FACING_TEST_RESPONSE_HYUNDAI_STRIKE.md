# 사용자 응답 테스트: 현대차 파업

테스트 일시: 2026-07-08  
테스트 입력:

```text
회사명: 현대차
입력 문장: 현대차 파업
```

---

## 사용자에게 보여줄 응답 예시

`현대차 파업`이라는 입력은 바로 `생산중단`으로 확정하면 위험합니다.

다만 여기서 분석을 끝내지는 않습니다.  
이 입력은 `비확정 선행 신호`이므로, 과거 유사한 파업 신호가 이후 어떻게 전개됐는지를 두 갈래로 나눠 볼 수 있습니다.

| 항목 | 판단 |
|---|---|
| 회사 | 현대차 |
| 입력 사건 | 파업 |
| 상태 | 비확정 선행 신호 |
| 앵커 후보 | 생산중단 |
| 확정 앵커 여부 | 아님 |
| 분석 방식 | 전환 시나리오와 회피 시나리오로 나눠 교육용 참고 |

---

## 먼저 구분해야 할 것

`파업`이라는 단어만으로는 실제 공장 가동이 중단됐는지 알 수 없습니다.

다음은 모두 다르게 봐야 합니다.

| 표현 | MVP 판단 |
|---|---|
| 파업 가능성 | 비확정 선행 신호 |
| 임단협 결렬 | 비확정 선행 신호 |
| 노조 찬반투표 | 비확정 선행 신호 |
| 총파업 예고 | 비확정 선행 신호 |
| 실제 생산중단 공시 | 확정 생산중단 앵커 가능 |
| 회사 공식 생산 차질 확인 | 확정 생산중단 앵커 가능 |
| 임단협 타결/파업 철회 | 파업 회피/합의 시나리오 |

현재 입력은 `생산중단 앵커`가 아니라 `생산중단 후보에 해당하는 비확정 선행 신호`입니다.

---

## 두 갈래로 봐야 하는 이유

파업 신호는 반드시 실제 생산중단으로 이어지지 않습니다.

따라서 사용자에게는 한 가지 결과만 보여주면 안 됩니다.

| 갈래 | 의미 | 기준일 |
|---|---|---|
| 파업 발생/생산중단 전환 | 파업 신호가 실제 파업, 조업중단, 생산 차질 공식 확인으로 이어진 경우 | 공식 생산중단일, 조업중단일, 회사 공식 확인일 |
| 파업 회피/합의/철회/타결 | 파업 신호가 임단협 타결, 파업 철회, 무분규 합의 등으로 끝난 경우 | 공식 합의일, 철회 발표일, 타결 발표일 |

현재 입력은 아직 어느 갈래인지 확정되지 않았습니다.  
그러므로 “현대차 파업이면 주가가 이렇게 움직인다”가 아니라, “과거에는 파업이 현실화된 경우와 피한 경우가 다르게 전개될 수 있었다”를 보여줘야 합니다.

---

## 3·5·10영업일 주가증감 표시 방식

이번 입력만으로는 단일 기준일을 확정할 수 없습니다.

대신 공식 기준일이 확인되면 아래처럼 두 갈래로 나눠 표시합니다.

| 시나리오 | 기준일 | 3영업일 후 | 5영업일 후 | 10영업일 후 |
|---|---|---:|---:|---:|
| 파업 발생/생산중단 전환 | 공식 생산중단일 확인 필요 | 확인 후 계산 | 확인 후 계산 | 확인 후 계산 |
| 파업 회피/합의/철회/타결 | 공식 합의/철회/타결일 확인 필요 | 확인 후 계산 | 확인 후 계산 | 확인 후 계산 |

이 표는 예측표가 아닙니다.  
두 시나리오 중 어느 쪽으로 갈지 단정하지 않습니다.

---

## 구간 내 보조 이벤트 확인

각 시나리오의 기준일이 확인되면, 주가증감과 함께 다음 구간을 확인해야 합니다.

| 확인 구간 | 확인할 내용 |
|---|---|
| 기준일 이전 1주일 | 파업 예고, 임단협 결렬, 노조 투표, 선반영 가능성 |
| 기준일~3영업일 | 실제 생산중단 여부, 회사 공식 입장, 자동차 업종 흐름 |
| 3~5영업일 | 후속 협상, 생산재개 가능성, 업종/시장 이벤트 |
| 5~10영업일 | 추가 공시, 환율, 관세/무역분쟁, 시장 급락/급등 |

이 구간의 주가증감은 기준 이벤트 하나만의 결과로 볼 수 없습니다.  
아래 기간에 다른 앵커 이벤트 또는 시장 맥락이 발생했는지 함께 확인해야 합니다.

---

## 교육 포인트

이번 입력에서 중요한 점은 `파업`을 하나의 확정 사건으로 보지 않는 것입니다.

초보 투자자는 “파업”이라는 단어를 보면 곧바로 악재나 생산중단으로 받아들이기 쉽지만, 실제로는 두 가지 가능성을 나눠야 합니다.

1. 파업이 실제 생산중단으로 이어진 경우
2. 파업을 피했거나 합의로 끝난 경우

그래서 플러그인은 `분석 보류`로만 끝내지 않고, 기준일이 확인되는 순간 두 갈래의 과거 사례를 나눠 3·5·10영업일 주가증감을 보여줘야 합니다.
