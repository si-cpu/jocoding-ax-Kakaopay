# 앵커 이벤트 사전

## 1. 목적

이 문서는 `Anchor Event Mapper` 플러그인이 비정형 입력을 어떤 공식 앵커 이벤트로 매핑할지 판단하기 위한 기준이다.

앵커 이벤트는 다음 조건을 만족해야 한다.

- 공식 출처로 기준일을 확인할 수 있다.
- 주가 증감 계산의 기준점으로 사용할 수 있다.
- 최근 1년 내 유사 이벤트 검색이 가능하다.
- 비정형 입력과 매핑될 때 포함/제외 조건을 판단할 수 있다.

## 2. 공통 원칙

### 2.1 기준일 규칙

이벤트 기준일은 발표 당일을 원칙으로 한다.

단, 시간상 시장 반영이 어려운 경우 다음 영업일을 기준일로 사용한다.

| 상황 | 기준일 |
|---|---|
| 장중 발표/공시 | 발표 당일 |
| 장마감 이후 발표/공시 | 다음 영업일 |
| 휴일 발표/공시 | 다음 영업일 |

### 2.2 업종 확장 기준

같은 회사의 유사 이벤트가 부족할 경우 같은 업종으로 확장할 수 있다.

업종 기준은 다음 순서로 적용한다.

1. KRX 업종 분류
2. 카카오페이증권 내부 종목 분류
3. 둘 다 확인할 수 없으면 업종 확장 보류

### 2.3 상태 구분

비정형 입력은 다음 상태 중 하나로 분류한다.

| 상태 | 처리 |
|---|---|
| 확정 | 공식 출처 기준일 확인 후 분석 가능 |
| 전망 | 앵커 후보로만 표시, 공식 출처 확인 전 분석 보류 |
| 우려 | 앵커 후보로만 표시, 공식 출처 확인 전 분석 보류 |
| 기대감 | 앵커 후보로만 표시하거나 분류 불가 처리 |
| 루머 | 분석 제외 |
| 해설 | 기준일 확인 불가 시 분석 제외 |

우려·전망·기대감은 지속적으로 반복 언급될 수 있으므로 독립 이벤트로 여러 번 세지 않는다. 참고가 필요한 경우 공식 출처에서 확인 가능한 가장 최근값만 사용한다.

## 3. 기업 앵커 이벤트

### 3.1 실적 발표

| 항목 | 내용 |
|---|---|
| 분류 | 기업 이벤트 |
| 공식 출처 | DART, 회사 IR, 실적 발표 자료 |
| 기준일 | 실적 발표일 |
| 포함 | 분기/반기/연간 실적 발표, 잠정 실적 공시 |
| 제외 | 실적 기대감, 애널리스트 전망, 업황 개선 해설 |

- “실적 전망”과 “실적 발표”는 분리한다.

## 5. 분석 제외 예시

다음 입력은 MVP에서 분석 제외 또는 보류한다.

- “요즘 이 종목 관심 많다던데?”
- “수혜주라던데?”
- “실적 좋아질 것 같다던데?”
- “파업할 수도 있다던데?”
- “정부가 뭔가 지원할 것 같다던데?”
- “저평가라던데?”
- “커뮤니티에서 악재라고 하던데?”

이 입력들은 공식 앵커 이벤트 후보로 볼 수는 있어도, 공식 출처 기준일이 확인되기 전에는 주가 증감 분석으로 연결하지 않는다.
