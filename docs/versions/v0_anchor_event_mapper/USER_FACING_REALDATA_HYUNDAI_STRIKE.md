## 사용자에게 보여줄 응답 예시

`현대차 파업`은 바로 `생산중단`으로 확정하면 안 됩니다.

현재 확인 가능한 실데이터 기준으로는, 2026-06-24에 현대차 국내 노조가 파업 찬성 투표를 했다는 보도가 확인됩니다.  
이 사건은 `파업 발생 가능성 신호`이지, 아직 `공식 생산중단` 자체는 아닙니다.

따라서 다음처럼 분류합니다.

| 항목 | 판단 |
|---|---|
| 회사 | 현대차 |
| 입력 사건 | 파업 |
| 확인된 기준 사건 | 2026-06-24 노조 파업 찬성 투표 |
| 상태 | 비확정 선행 신호 |

| 분석 방식 | 파업 발생/생산중단 전환 가능성과 파업 회피/합의 가능성을 분리 |

## 갈래 1: 파업 발생/생산중단 전환 가능성

현재 확인된 사건은 `파업 찬성 투표`입니다.

이는 실제 파업이나 생산중단으로 이어질 수 있는 선행 신호지만, 그 자체가 생산중단은 아닙니다.

기준일: 2026-06-24  
기준 종가: 509,000원

| 구간 | 비교일 | 종가 | 기준일 대비 주가증감 |
|---|---:|---:|---:|
| 3영업일 후 | 2026-06-29 | 497,000원 | -12,000원 / -2.36% |
| 5영업일 후 | 2026-07-01 | 487,500원 | -21,500원 / -4.22% |
| 10영업일 후 | 2026-07-08 | 462,500원 | -46,500원 / -9.14% |

해석:

- 이 수치는 “파업 찬성 투표 이후 현대차 주가가 이렇게 움직였다”는 뜻입니다.
- “파업 때문에 주가가 하락했다”는 뜻이 아닙니다.
- 실제 생산중단이 있었는지, 중간에 다른 자동차 업종/시장 이벤트가 있었는지 확인해야 합니다.

## 갈래 2: 파업 회피/합의/철회/타결 가능성

이번 조회에서는 현대차 국내 노조의 `파업 회피`, `합의`, `철회`, `타결`에 해당하는 공식 기준일을 확정하지 못했습니다.

따라서 이 갈래의 3·5·10영업일 주가증감은 계산하지 않습니다.

| 항목 | 결과 |

| 3영업일 후 주가증감 | 계산 보류 |

- 파업 철회 발표일
- 회사 또는 노조의 공식 타결 발표일

## 교육 포인트

이 사례에서 중요한 점은 `파업 찬성 투표`와 `실제 생산중단`을 분리하는 것입니다.

초보 투자자는 “파업”이라는 단어만 보고 바로 악재나 생산중단으로 받아들이기 쉽지만, 실제로는 두 갈래를 나눠야 합니다.

1. 파업 신호가 실제 파업/생산중단으로 전환된 경우
2. 파업 신호가 합의·철회·타결로 끝난 경우

이번 실데이터에서는 1번의 선행 신호 기준일은 확인됐지만, 2번의 공식 기준일은 아직 확인하지 못했습니다.

따라서 현재 보여줄 수 있는 것은 `파업 찬성 투표 이후 주가증감`이지, `파업 발생 효과`가 아닙니다.
